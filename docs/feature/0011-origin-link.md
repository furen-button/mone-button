# Feature 0011: 元動画情報表示機能

## 概要
- **機能名**: 元動画情報表示機能
- **ID**: 0011
- **カテゴリ**: リンク
- **優先度**: 低

## 機能要件
ボイスカードにあるインフォボタンをクリックで元動画の情報を表示する。

- 元動画のタイトル、配信日を表示
- セリフ、ルビ、カテゴリーの情報も表示
- ボイスの開始位置へのリンクを提供
- 新しいタブで元動画を開く

## UI
- **ボタン**: インフォアイコン（i）を使用
- **表示位置**: ボイスカード内

## 動作要件
- インフォボタンをクリックすると、元動画の情報がポップアップで表示される
- ポップアップ内のリンクをクリックすると、元動画が新しいタブで開かれる
