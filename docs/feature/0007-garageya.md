# Feature 0007: わいわいガヤガヤ

## 概要
- **機能名**: わいわいガヤガヤ
- **ID**: 0007
- **カテゴリ**: 特殊再生
- **優先度**: 低

## 機能要件
複数の動画を同時に再生する。
再生の位置パターンは被らないように複数用意して、ランダムに選ばれる。

連続再生がオンのとき、動画の再生が終わると動画が消えて次の動画がランダムな位置で再生される。

## UI
- **同時再生**: 複数の動画が同時に画面に
- **ランダム位置**: 位置がバラバラな演出をするが、被らないように配置する
  - [(x,y)座標の例] [(width * 1 / 8, height * 1 / 8), (width * 3 / 8, height * 5 / 8), (width * 5 / 8, height * 3 / 8), (width * 7 / 8, height * 7 / 8)] などの位置パターンを用意し、ランダムに選択する

## 動作要件
- 複数の動画を同時に再生
- ランダム位置配置
- 重なりの演出
