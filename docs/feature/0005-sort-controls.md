# Feature 0005: ソートコントロール

## 概要
- **機能名**: ソートコントロール
- **ID**: 0005
- **カテゴリ**: 表示
- **優先度**: 中

## 機能要件
ボイスの並び順を制御する。

## UI
- **表示位置**: カテゴリフィルターの下
- **ソートタイプ**: 読み順、配信別（配信日降順）、配信別（配信日昇順）
- **アイコン表示**: ソートタイプに応じたアイコンを表示
- 配信別ソート時「配信ごとの見出し（動画タイトル・配信日・リンク）」を区切り表示する
- 配信別ソート時、同一配信内のボイスをstartTimeの早い順に並べる

## 動作要件
- ソートキー選択
- 並び順切り替え
- 状態保持
