# セリフボックスの顔回避

## 目的

セリフボックスが演者の顔（口・あご）を隠さないようにする。既定プリセットのボックスは固定幅（画面幅 − 左右マージン = 1612px）で画面下端に張り付いており、右側に立つ演者の顔下部に重なっていた。

## 実測（2026-09-11、1920x1080）

| 動画 | 顔の矩形 | ボックス上端 | 重なり |
|---|---|---|---|
| 既定プリセット（zoom なし、不透明ボックス） | y 628〜993 | y 891 | 64〜102px。口が完全に隠れる |
| config-matome-01（zoom あり、半透明） | y 495〜987 | y 891 | 30〜96px。透けるがあご〜首に掛かる |

ボックスの下には 49px しか余白が無く、1 行ボックス（140px）は下に逃がせない。文字を小さくして箱を低くする案も試したが、あごに掛かったまま文字だけ小さくなった。**顔の無い側へ寄せて幅を狭める**案だけが解消した。

## 実装

| 項目 | 内容 |
|---|---|
| `avoid.js` | `planSerifAvoidance`（検出→判断）と純関数 `chooseAvoidance`（左右どちらへ寄せるか・幅の下限） |
| `effects.js` | `detectFaceRects`（zoom と同じ検出器で顔矩形を返す）、`zoomCropRect` / `transformRectThroughZoom`（切り出し後座標への変換） |
| `ass.js` | `makeTextElement` に `marginL` / `marginR`。折り返し幅と `textBoxRect` の両方が従う。未指定なら従来どおり左右対称（ASS ゴールデンで確認） |
| `clip.js` | zoom 計画 → 顔回避 → 要素生成の順に並べ替え。判断を `avoid` として返す |
| `config.js` / schema | `telops.serif.avoidFace { enabled, gap, minWidth, frames }`、CLI `--avoid-face` / `--no-avoid-face` |
| manifest / QC | `avoidFace` を記録。見送り（`fallback`）は `serif_face_fallback` の warn |

### 判断の流れ

1. クリップ全体に `frames` 枚を散らして顔を検出。検出した矩形はすべて合成（演者が動いても避ける）
2. zoom が効く区間は切り出し後の座標へ変換。punch は開始前後の両座標で避ける
3. 避ける前のボックスと重ならなければ何もしない
4. 顔の左右で広い側を選び、`gap` を空けてボックスを収める。幅が `minWidth` 未満なら見送り（全幅のまま、QC warn）

## 結果

同じクリップ（2024-07-13-gr9WJDYS_u0-000104-000106）で確認。

| プリセット | 顔（出力座標） | ボックス | 描画後の再検出との重なり |
|---|---|---|---|
| 既定 | x 1355〜1730 | x 154〜1331（幅 1177） | なし |
| config-matome-01（zoom 1.3 全編） | x 1189〜1660 | x 154〜1165（幅 1011） | なし |

- `npm test` 80 件成功（新規 7 件: `chooseAvoidance` の左右・見送り・手動指定、非対称マージンの幅・位置・折り返し）
- ASS ゴールデン 327 通り一致（`marginL/R` 未指定の経路は無変更）
- 顔検出はクリップごとに 3 フレーム抽出 + 1 回の検出で、19 クリップで十数秒の追加

### 19 クリップ全体（既定プリセット、gr9WJDYS_u0）

- 19/19 で顔を検出し全件に適用（すべて左寄せ）。見送り 0。ボックス幅 1612px → 1032〜1261px
- コンタクトシート 19 マスすべてで口・あごが見える
- クリップ全体に散らした 3 フレームを合成する方式で検出率が上がった（単発フレームでは 6 枚中 2 枚しか拾えなかった）

### 副作用: 語中改行

幅が約 2/3 になるため 1 行だったセリフが 2 行に折れるものが増え、「やめ / て」「ダッ / シュ」「助か / らない」のように語中で切れる箇所が出る。日本語は語境界が無いので `wrapText` は禁則以外では単位で切る。緩和策は次のいずれか（未決定）。

- `avoidFace.gap` / `minWidth` を詰めて幅を稼ぐ
- 該当クリップの `serif` に手動改行を入れる（動画生成は手動改行を尊重し、サイト表示では無視される）
- 語境界（助詞・記号・かな漢字の切り替わり）を優先する折り返しを `wrapText` に足す

## 注意

- 折り返し幅が狭くなるため、長いセリフは行数が増える。`autoShrink` が効いて文字が小さくなることがある
- 顔が中央にあるクリップは両側とも幅が足りず見送りになる。QC の `serif_face_fallback` で把握し、必要なら `effects.avoidFace: {"side": ...}` で寄せる側を指定するか、セリフを分割する
- 検出はアニメ顔用カスケード。演者が映っていないクリップやゲーム画面の顔らしい模様で誤検出する可能性はある。判断は render.json に残るので、コンタクトシートと併せて確認する
