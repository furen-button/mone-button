
# 【サイト仕様書】もねボタン

## 1. サイト概要

* **サイト名:** もねボタン
* **概要:** にじさんじ所属のVTuber「梢桃音」の配信から抜粋されたボイス（音声切り抜き）を、ボタンひとつで再生できるWebアプリケーション。「宇志海ボタン」など、界隈で親しまれている音声ボタンサイトのオマージュとして制作されている。
* **目的・スタンス:** ファンのためのエンターテインメント提供。ANYCOLORの二次創作ガイドラインに準拠し、ライバーへの敬意と創作性を持って運営されている。

## 2. メイン機能（音声再生・操作機能）

ユーザーがボイスを再生・コントロールするための主要機能群です。

* **単発再生:** 一覧表示されている各ボイスのボタン（「散！」「こんもね」など）をクリックすることで、該当する動画ファイルが再生される。画面上のランダムな位置に動画表示される。
* **特殊再生コントロール:**
* **わいわいガヤガヤ:** 複数の音声をランダムに重ねて連続再生する。
* **連続再生:** 登録されている音声を順番に連続で再生する。
* **ランダム連続再生:** 登録されている音声をランダムな順序で連続再生する。
* **停止:** 現在再生中のすべての音声を強制停止する。

## 3. 画面UI・表示コントロール仕様

膨大な音声データをユーザーが探しやすく、使いやすくするためのインターフェース仕様です。

* **カテゴリフィルター機能:**
* 音声を属性ごとに分類（例：`collab`、`emotions`、`game`、`kawaii`、`meigen`、`outa`、`waraigoe` など全26カテゴリ）。
* チェックボックスにより、特定のカテゴリのみを絞り込んで表示可能。
* 「カテゴリー全チェック」「カテゴリー全解除」のオンオフ一括操作ボタンを配置。

* **ソート（並び替え）機能:**
* **読み順:** ボイス名の五十音（アルファベット）順に表示。
* **配信別:** 切り抜き元の配信アーカイブごとにまとめて表示。
* **再生数順:** クリック（再生）された回数が多い順に表示。

* **音量調整:** スライダーによる全体のボリュームコントロール機能（※一部のスマートフォン等端末ではOSの仕様上無効）。

## 4. データ・メタデータ仕様

* **元動画へのリンク（出典明記）:**
* 各ボイスボタンに付随する「i（インフォメーション）」アイコンをクリックすると、切り抜き元の元動画（YouTubeアーカイブ等）やクリップへのリンク先を確認できる。

* **トラッキングカウンター:**
* **総再生回数:** サイト全体でのボイス合計再生数を表示。
* **あなたの再生回数:** ユーザー自身（現在のブラウザ環境）が再生した回数をカウントして表示。



## 5. 運用・システム関連

* **更新履歴表示:** トップページ上部に、ボイスや効果音が追加された日付と内容（例：「2025-12-31 : おみせっちの効果音追加」など）がリスト表示される。
* **外部連携・リンク集:**
* 制作者・関連アカウントへのリンク。
