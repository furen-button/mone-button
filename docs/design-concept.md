# デザインコンセプト：もねボタン

## コンセプト名
### 「ボタンの魔法」

## 理念
「ボタンの魔法」は、梢桃音さんの可愛らしいボイスが、
まるで魔法のように画面を彩るような体験を提供することをコンセプトにしています。

## 色彩システム

### 主要色

- ** Main Pink**: `#FFC6E2` - メインのピンク色
  - 再生ボタンや主要アクションに使用
- ** Soft Purple**: `#DECDFC` - 優しい紫色
  - ホバー状態や強調表示に使用
- ** Base White**: `#FFFFFF` - 基本的な背景色
- ** Soft Cream**: `#FFF9F0` - 読みやすくソフトな背景

### 背景表現
画面背景を、ボイスごとにランダムに変化させる「季節の風景」を
視覚効果として提案しています。桜の花びら、夜空、星空、雪など、
梢桃音さんのイメージに合わせた演出を。

モチーフ花：桃の花（ファンマークは🪷）

## タイポグラフィ

### フォント
- 日本語：`Noto Sans JP` または同等の可読性を兼ね備えたゴシック体
- ラテン文字：`Inter` または同等の読みやすいサンセリフ体

### ヒエラルキー
- H1: `2rem / 1.2` - サイトタイトル
- H2: `1.5rem / 1.3` - 主要セクション
- H3: `1.25rem / 1.4` - サブセクション
- Body: `1rem / 1.6` - 基本テキスト
- Button: `0.85rem / 1.5` - ボタンテキスト（太字）

## UI グリッド

### レイアウト
- ブロックグリッド採用：画面を 12 コラム、6 ローのグリッドに分け
- ボイスカード：6 x 6 のブロック（スマホでは 4 x 4）
- カテゴリフィルター：12 コラムを横に並べる
- 音量スライダー：画面下部に固定表示（8 コラム幅）

### カードデザイン
- 白地＋微細な影を持つカード
- ホバー時にわずかに浮き上がる表現
- ボイス名をクリック：再生＆ランダムに飛ぶアニメーション

## アニメーション

### 再生演出
- ボタンクリック時から 0.3 セクンドの遅延で、
  画面右上からランダムな位置に動画表示
- 動画アイコンが「ドドーン♪」と弾けるアニメーション
- 再生中：動画がゆっくりとふわふわと浮遊

### 特殊再生
- **わいわいガヤガヤ**: 複数の動画がランダムな位置に同時に出現
- **連続再生**: 動画がチェーンのように連続出現
- **停止ボタン**: 全ての動画が「ドスン」と小さくなって消える

## 音声デザイン

- プレイヤーを画面中央に配置、ボタンのような丸みのあるデザイン
- 再生ボタン：円形、赤、中央に小さなアイコン
- 進捗バー：透明度 80% のセクションの境界
- 音量コントロール：スライダー＋アイコン表示

## データビジュアライゼーション

- 再生回数の表示
  - 総再生数: 大きな数字＋単位
  - 個人再生数: ユーザーアイコン＋数字
- カテゴリ数表示: カテゴリフィルターの上部に丸バブルのインジケーター

## アクセシビリティ

- 色覚多様性対応：コントラスト比 4.5:1 以上
- 音声の代わりに：ボイス名＋カテゴリをテキスト表示
- 焦点リング：キーボード操作中に明確な視認性

## エモーショナル・ゴール

「もねボタン」は、ユーザーに以下のような感情を提供する場所です：

1. **癒やし** - 可愛いボイスが心を和らげる
2. **驚き** - 画面に動画が突然出现する演出
3. **楽しみ** - いつでも楽しめるコンテンツ
4. **コミュニティ** - みんなで使っている感覚
